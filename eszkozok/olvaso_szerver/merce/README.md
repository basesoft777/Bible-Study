# merce/ — az olvasói pillanatkép (F232)

Lapranként egy szöveges fájl: a `teszt_olvasoi_merce.py` normalizált képe az olvasó mintalapjairól (a mai állapot, hibáival együtt).
Frissítése csak a `python teszt_olvasoi_merce.py --merce-frissit` paranccsal, a felhasználó jóváhagyásával; a PR leírása hivatkozik rá.
